## Capstone (dependency, not vendored)
PyPI was not reachable from the workspace, so Capstone 5.0.3 (BSD-3-Clause)
was built from source:

```sh
git clone --depth 1 --branch 5.0.3 https://github.com/capstone-engine/capstone.git
cd capstone
cmake -B build -DBUILD_SHARED_LIBS=ON -DCAPSTONE_ARCHITECTURE_DEFAULT=OFF \
      -DCAPSTONE_X86_SUPPORT=ON -DCMAKE_BUILD_TYPE=Release
cmake --build build -j8
SP=$(python3 -c "import site;print(site.getsitepackages()[0])")
cp -r bindings/python/capstone "$SP/"
mkdir -p "$SP/capstone/lib"
cp -L build/libcapstone.so.5 "$SP/capstone/lib/libcapstone.so"   # .dylib on macOS
```
Where PyPI is reachable, `pip install capstone==5.0.3` is the simpler route.
